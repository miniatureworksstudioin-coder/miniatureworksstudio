The brief

A shop that can't oversell what hasn't been built yet

Miniature Works Studio hand-builds furniture miniatures, architectural models and one-off commissions — dioramas, hand mirrors, dollhouse furniture, prototypes. Nothing is mass-produced, and nothing is kept on a shelf: every order is built after it's placed, usually over 10–15 working days.

That rules out a standard e-commerce template. There's no fixed catalogue, no stock counter, no single price per item — a hand mirror in Small is a different build, and a different price, from the same design in Large. The site needed to sell a process, not a warehouse.

It also needed to run a whole small business on its own: take custom commissions with reference photos, let customers check on an order without creating an account, collect reviews without letting anyone post directly, and give the studio a way to manage all of it without a spreadsheet.

Design system

A palette borrowed from the workshop itself

Every piece the studio makes starts as pale MDF and darkens through a hardening process — no paint, no stain. The site's palette follows the same logic: paper, walnut and brass, nothing added that isn't structural.

What it does

Nine problems, one page

Rather than a shop plus a separate booking form plus a separate FAQ, everything lives in one continuously scrolling site — each section solving one specific part of running a made-to-order business.

01

Sized, not stocked

Every piece shows Small / Medium / Large pricing plus a Custom/XL quote path — no unit is ever marked "in stock."

02

Order drawer

A slide-in cart with a quantity stepper and a choice between paid home delivery or free local pickup at the studio.

03

Custom commissions

A dedicated form for one-off briefs, with reference-photo upload and approximate size, separate from the fixed catalogue.

04

OTP-verified checkout

A customer must prove they own their phone number — via a code sent to their email — before an order can be placed. The same one-time code later unlocks order tracking and full order history, with no account required.

05

Moderated reviews

Star ratings and comments are submitted publicly but held back until the studio approves them.

06

Studio dashboard

A sign-in-gated admin view for moving orders through confirmed → in progress → ready → completed, and approving reviews.

07

Zoomable gallery

A lightbox with per-piece extra shots, swiped through without leaving the page.

08

Structured data

Every piece is marked up as a schema.org Product with size-based offers, so search engines see real pricing.

09

Printable receipts

A dedicated print stylesheet strips the nav, drawer and modals so a confirmation prints cleanly on paper.

Under the hood

No framework, no accounts, still stateful

The front end is plain HTML, CSS and JavaScript — no build step. Orders, custom requests and reviews are handled by serverless functions backed by Netlify Blobs and Supabase, and order tracking runs entirely on one-time codes instead of a login system.

Small decisions

The details that don't show up in a feature list

One orchestrated entrance

The homepage plays a single load-in sequence — headline, then image, then corner marks. Every other transition only fires in response to something the visitor does.

Reduced motion, respected

Every animated element collapses to an instant, static state under prefers-reduced-motion — including the lightbox and the order drawer.

Readable order IDs

Orders are stamped as MWS-YYMMDD-#### — a customer can tell how old an order is just by reading the ID back over the phone.

A named pickup point

Local pickup names the actual studio location near Modinagar North RRTS station, instead of a generic "select a store" step.

Real starting prices

Every size tier's price was set from the studio's own materials and build-time costs, not placeholder numbers, before the catalogue went live.

Print as a real output

An order confirmation is expected to be printed and kept — so the print stylesheet is treated as its own layout, not an afterthought.
